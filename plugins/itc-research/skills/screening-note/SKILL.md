# Screening note

Write an Investors Trust Company internal research note screening several (typically 3-6) unrelated names against each other, in Dana's house style.

## Before drafting

1. Read `house-style.md` from Dana's Investors Trust > Equity Research folder (create from `references/house-style-seed.md` if missing).
2. Confirm the purpose is relative — deciding where to spend further diligence time — not proving one name is a buy. Say so explicitly in the note if the businesses share little operationally.
3. Gather primary sources for each name (10-Ks/10-Qs, most recent transcript, FactSet consensus/comps).

## Structure

1. Masthead + title naming all screened tickers and framing the purpose ("screening a four-name universe" style)
2. Byline, sources line
3. Overview: give the short version up front — which names are clean passes, clean buys (rare), or genuinely undecided, and why
4. Per-company section: what the business does and is trying to do, kept tight
5. A relative-comparison section: growth quality, valuation, and the shape of near-term risk for each, set against each other rather than in isolation
6. Explicit callout of the specific overhang or missing proof point holding back any name that isn't a clean pass
7. Close with a ranked recommendation on where to spend further diligence time, not a single pick

## Save the file

Name it `YYYY-MM-DD_ITC_ScreeningNote_DanaBriner_v01.docx`, saved to `Equity Research/Research Notes/Screening Notes/`.
