# Notion databases

| Database | Key properties |
|---|---|
| **Firms** | Name, Category, Key Takeaways, Recruiting Timeline |
| **Opportunities** | Name, Firm (→ Firms), Group / Role, Stage (Not started / In progress / Submitted / Interviewing / Offer / Rejected), Season, Type, Location, Opened, Deadline, Deadline Type, URL, Priority |
| **People** | Name, Firm (→ Firms), Role & About, Location, Level, Type, Connection, Source, Call Date |
| **Tasks** | Name, Due, Status, related Opportunity or Person |
| **Technicals Bank** | Question, Topic, Source, Number, Sent (date), Got it right |

Also used: a **Careers Check Log** page (working endpoints, run history, concepts already taught) and a **Resume** page (source facts for letters and briefs).
